# Crime Intelligence Database System - MVP

## Description
A desktop application for managing criminal intelligence data, including person records, biometrics, and case management.

## Technology Stack
- **Language:** Python 3.11+
- **GUI Framework:** PyQt6
- **Database:** SQLite (MVP), PostgreSQL (future)
- **ORM:** SQLAlchemy
